# ROOMIFY — Interactive 3D Room Interior Designer & Space Planner

## Folder Structure
- `index.html` — Landing page
- `dashboard.html` — My Designs workspace & project manager
- `editor.html` — Interactive 3D & 2D Cutaway Room Designer
- `assets/css/` — Modular stylesheets (`style.css`, `dashboard.css`, `editor.css`)
- `assets/js/` — Modular Three.js & application scripts (`main.js`, `dashboard.js`, `materials.js`, `furniture.js`, `lighting.js`, `camera.js`, `budget.js`, `export.js`, `room3d.js`)
- `server.js` & `package.json` — Node.js / Express backend for Render & localhost

## Deploy on Render (Free)
1. Push the `ROOMIFY` folder to GitHub.
2. On Render, create a **Web Service** (`Build Command: npm install`, `Start Command: npm start`, `Plan: Free`) OR a **Static Site** (`Publish Directory: .`).
